# Security

Do not post API keys, chat content, telephone numbers, signing keys, or private documents in public issues.

The APK does not ship a shared provider credential. User-entered keys use Android Keystore backed AES-GCM and app backups are disabled. This does not protect against a rooted, instrumented or otherwise compromised device. Revoke a key at the provider if you suspect exposure.

Inputs and model output are untrusted. Execution is limited to fixed local tools; no shell commands, dynamically loaded code or model-selected recipient is executed. XML external entities, unsafe ZIP paths, macros, external worksheet links and cached input formulas are rejected. File and model output sizes are bounded.

WhatsApp delivery is an experimental, version-scoped accessibility adapter. It validates the visible destination, file, caption and provider read, records an attempt before the irreversible send, and does not blindly retry. A queued message is not a delivered message. Do not use it where a failed or misdirected message would be unacceptable.

For a suspected vulnerability, use GitHub's private vulnerability reporting where enabled. Otherwise open an issue describing only the affected component and asking for a private contact channel; do not disclose exploit details or secrets publicly.
