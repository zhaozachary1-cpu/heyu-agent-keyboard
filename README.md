# 禾语 Agent 输入法

**Android AI 输入法：用户自带 DeepSeek API Key，手机直接推理，文件在手机本地生成。**

不需要 Mac、USB 桥接、同一局域网或自建服务器。普通打字和拼音在本机运行；AI 功能需要联网访问 DeepSeek。

[English](README.en.md) · [隐私说明](PRIVACY.md) · [构建说明](docs/BUILD.md) · [架构](docs/ARCHITECTURE.md) · [测试记录](docs/VALIDATION.md)

## 能做什么

- 中文拼音、英文、符号输入；输入法内部字段使用同一套键盘编辑。
- **AI 润色**：正式、务实、自然、亲和、简洁五种风格。直接替换当前草稿，短时可撤销，不替你发送。
- **回复建议**：用户单独授权后，基于 WhatsApp 当前可见文字生成建议；点选才填入，已有草稿不覆盖。
- **帮我做**：优先识别聊天里的任务，也允许手动选择目标；核对计划后才执行。
- **本机文件**：PPTX、DOCX、PDF、XLSX、PNG/JPEG、ICS。模型编写和规划，本机程序负责排版、计算和文件导出。
- **本机记录**：按当前可识别会话隔离任务与历史，可在历史中查看和删除。没有云端历史服务。
- **文件交付**：针对已适配的 WhatsApp 界面，用户逐份点选后核对接收人和原生预览再发送；保留系统分享方式。

## 安装与开始使用

1. 从本仓库 **Releases** 下载 APK，或者自行构建。Android 11 / API 30及以上，提供arm64-v8a和x86_64。
2. 打开“禾语 Agent”，在系统中启用并选择禾语输入法。
3. 进入 **配置我的 DeepSeek Key**，填写你自己的 Key，保存后点 **测试模型连接**。默认模型为 `deepseek-flash`，使用各自的DeepSeek账户和额度。
4. 在任意普通文字输入框试用润色。普通打字不需要模型Key。
5. 如果要在 WhatsApp 使用上下文功能，阅读应用内说明后分别开启上下文辅助及自动回复授权。一键文件交付另行授权。

**仓库和APK不提供共享模型密钥。不要把自己的Key提交到Issue、日志、截图或代码。** 模型Key使用Android Keystore加密后保存在本机，APK禁用系统备份；这不等于能防御已被Root或完全控制的设备。

## 七类本机任务

| 结果 | 支持范围 |
|---|---|
| PPT | 3–10页文字型演示，固定简洁模板 |
| 文档 | 文字型DOCX和分页PDF，保留未确认事项 |
| 清单/报价 | 数量清单或明确单价/币种的报价；BigDecimal计算，行金额先四舍五入再合计 |
| 表格分析 | 单表、单维度分组、sum/count/average、最多3个AND过滤条件；结果和原始数据工作表及图表 |
| 图片处理 | 指定坐标裁剪/遮挡、旋转、等比缩放、水印、拼图、JPEG质量压缩；不自动识别所有隐私 |
| 翻译材料 | 明确目标语言的逐段双语DOCX/PDF |
| 待办/日程 | 已提供的事项、负责人、绝对起止日期时间；输出DOCX/PDF/ICS，不自动发邀请或写日历 |

可选材料：TXT、CSV、XLSX、DOCX、文字型PDF、PNG/JPEG/WebP。默认最多4份、每份8MB，总24MB；表格最多1000行30列；PDF不超过20页，不支持加密文件或扫描OCR。带公式的输入表格需先导出纯值版本，避免把旧计算缓存当成当前值。

## 实现与使用边界

这是可运行的开源演示版本，不是Gboard引擎，也不是WhatsApp官方产品或Business API集成。当前文件交付适配是版本限定的原生界面流程：已验证的版本见[测试记录](docs/VALIDATION.md)。未知版本/页面、错误联系人、非空草稿或不明确的发送状态会阻止操作，不后台重复发文件。

- 不支持语音输入、滑行输入、个性化纠错、创意生图、扫描OCR、任意复杂Office原版式复刻。
- AI结果需核对；金额由代码算，但输入信息仍可能被模型识别错误。
- 跨新窗口/重启没有稳定WhatsApp账号与联系人ID，不能按昵称自动合并旧记录；旧材料可能需要明确归属确认。
- 长任务在应用进程被系统结束后可能中断，不把它冒充云端持久队列。
- 本地临时文件仍须保留到目标应用读取完毕；删除本机记录不会撤回已发出的消息，也不会删除服务商已接收的请求。

## 构建

准备JDK17+、Python3、Android SDK平台36、Build Tools36.0.0、NDK29.0.14206865、zip/unzip：

```sh
export ANDROID_HOME=/path/to/android-sdk
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/29.0.14206865"
bash build.sh
bash scripts/test-release.sh
```

生成：`output/heyu-agent-1.0.0.apk`。构建不需要任何模型Key，也不读取其他项目的配置。依赖从Maven Central按固定版本和SHA-256校验获取。自行构建时默认生成仅你本地持有的测试签名；正式分发使用自己的持久签名配置，详见[构建说明](docs/BUILD.md)。
