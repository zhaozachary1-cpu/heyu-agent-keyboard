# 独立版验证记录

验证日期：2026-10-10。Android独立版1.0.0，测试设备OnePlus PGZ110 / Android15。测试使用合成数据及测试人员自己的DeepSeek账户；不发布密钥、联系人身份、聊天内容、设备序列号或私人截图。

## 已验证

- **无Mac服务依赖**：测试前停止旧Mac本地/LAN服务、删除ADB反向映射。正式APK不包含bridge.json、本地服务地址、私有CA或模型Key；请求直接到DeepSeek官方HTTPS接口，文件工具运行于Android。
- **真实API与手机执行器**：回复、润色、任务识别及PPT/文档/报价/表格分析/图片/翻译/日程七类任务产出真实结果。七类产物共54项校验通过，包括手机端文件hash、Office格式可打开性、PPT页数、报价舍入、表格过滤、图片尺寸/遮挡、翻译条件、日历UTC时间等。
- **正式生产界面**：填写本机Key、模型连接测试、润色原位替换与撤销、后续输入、Word/PDF本机生成和历史缓存通过。
- **系统文件选择器**：合成CSV从系统选择器回到原宿主，保留原任务/材料，随后本地分析完成；没有跳到旧设置页。
- **文件交付**：本机生成的合成DOCX经一次结果卡点击交给指定的授权测试会话，原生回执为“已发送”。本轮没有得到“已送达”的确认；不把单勾、文件气泡或点击成功当成送达，也没有重复提交。
- **输入回归**：既有离线回归220项通过；原生拼音149137次合成搜索在普通构建及ASan/UBSan构建下通过。公开发布合约检查9项通过；Android本机解析与执行保护25项断言通过。
- **Key与发布包**：生产APK无QA接收器/密钥注入接口。Key经密码字段保存于Android Keystore加密存储，一次性测试输入文件随即删除。Git实际索引及APK进行敏感内容扫描，私有运行目录和历史实验没有上传。
- **产物可读性**：DOCX/PPTX/XLSX用独立桌面阅读器打开；PDF直接读取、渲染；图片实际像素检查。桌面工具只做结果检查，没有替手机生成产物。

ADB仍用于安装、操作合成测试界面和读回证据；它不转发服务流量，也不承载模型请求/文件生成。测试没有声称已执行人工物理拔线动作。

## 验证中发现并处理

- 根据Android SDK API版本表检查，将API33才有的String.isBlank和InputStream.readAllBytes替换为API30可用的等价有界实现。
- Key输入框显式设置密码变换及安全窗口标志；保存后清空输入值，连接状态不回显Key。
- 手机模型请求增加整体截止时间，避免单个读取超时不能终止整个请求。早期隔离测试出现等待异常，保留记录；之后按任务逐项复测成功，不据此承诺所有网络下均稳定。
- 表格导出保留精确单价和公式缓存，并加入打印按页宽缩放；文档仍是固定模板，不保证复杂原版式。
- 文件选择器使用独立任务栈和有时限的原宿主事务。恢复必须匹配原工作区/窗口，不通过联系人同名来合并数据。

## 尚未覆盖/不能扩大解释

- 广泛机型、全部Android版本、所有语言和聊天应用没有全覆盖。
- WhatsApp单次交付仍只对已适配的2.26.38.73/74界面放行；未知版本或未知界面拒绝执行。不是官方API，也不保证平台升级后无需适配。
- 进程长期后台存活、极弱网、应用强制终止、重启后的运行中任务恢复仍有限。
- 真机本轮没有重新测试每一种文件格式最终发给收件人、日历真实写入或任意复杂文件编辑。
- 历史在本机保存，不代表云同步或稳定跨窗口联系人ID；可以查看/删除，不按昵称自动借用其他工作区。
- 模型生成和提炼仍可能错误。输入限制、来源核查和确定性计算降低风险，不构成事实/业务正确性保证。
